HTTP(fetch) Asset Resolution

Resolves a USD scene's external assets — sublayers, references, payloads, and textures — over the network with fetch(). Relative paths are rewritten onto the source host; composition arcs resolve first, then textures. MaterialX and UsdPreviewSurface shade through one tydra-unified path. Rendering keeps textures encoded (decoded in JS off the WASM heap) and frees the WASM scene after GPU upload — the low-memory streaming path applied to an HTTP-composed scene.

A local .usda whose texture is an absolute https:// URL — fetched over HTTP, then rendered.

② Root USD over HTTP

Root loaded from a remote host (default: usd-wg/assets test_assets); every relative reference/texture is rewritten onto its directory and pulled over HTTP. Edit the URL for other assets. Drag to orbit, wheel to zoom.
